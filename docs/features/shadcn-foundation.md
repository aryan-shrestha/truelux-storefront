# shadcn foundation

Status: Implemented

Last updated: 2026-09-25

---

## Goal

Make shadcn/ui the storefront's only component library (ADR 0009), themed to
TrueLux, and replace the hand-built primitives the fork inherited.

---

## Scope

What is included in this implementation?

- `shadcn init` (Radix base, CSS variables, Tailwind v4), with `components.json`
  committed
- Theme tokens in `app/globals.css` as shadcn variables, in light and dark,
  expressing the TrueLux direction (ADR 0010)
- The inherited `components/ui/*` replaced by shadcn components
- Further components added as features need them
- `Price` stays, as the one place money is formatted
- Existing tests keep passing, updated for the new markup

What is explicitly outside the scope?

- Storybook or a component gallery

## Context

`npx shadcn@latest init -b radix -p nova -y --no-monorepo --no-rtl` ran against the
existing `globals.css`, which was then rewritten around the TrueLux tokens (see
[design-system.md](design-system.md)).

## Implemented

- `components.json`: style `radix-nova`, RSC, Tailwind v4 CSS variables, icon
  library `lucide`, and **`aliases.utils` set to `cn`** (the npm package), so
  generated files import `{ cn } from "cn"` and there is no `lib/utils.ts`.
- `components/ui/`, generated by the CLI:
  `accordion`, `alert`, `badge`, `breadcrumb`, `button`, `button-group`, `card`,
  `carousel`, `command`, `dialog`, `empty`, `field`, `input`, `input-group`,
  `label`, `native-select`, `navigation-menu`, `pagination`, `popover`,
  `separator`, `sheet`, `skeleton`, `spinner`, `textarea`, `toggle`,
  `toggle-group`. `price.tsx` sits beside them.
- The replacements:

  | Inherited | Now |
  | --- | --- |
  | `Button` | `button` (a spinner is composed in; there is no `pending` prop) |
  | `Dialog` (mobile menu) | `sheet`, from the left |
  | `Sheet` (cart) | `sheet`, from the right |
  | `Combobox` (district) | `command` in a `popover`, `components/checkout/DistrictPicker.tsx` |
  | `Radio` (variant picker, payment) | `toggle-group`; the payment choice is gone (COD only) |
  | `Skeleton`, `Spinner` | `skeleton`, `spinner` |
  | `Field` | `field` + `input` + `label` + `textarea` |
  | `Quantity` | `button-group` + `input`, `components/cart/QuantityStepper.tsx` |
  | `Chevron`, inline SVG icons | `lucide-react` |
  | Gallery's scroll-snap track | `carousel` (Embla) |
  | Hand-styled pagination links | `pagination`, rendering `next/link` |
  | Empty-state panels | `empty` |
  | Failure notices | `alert` |

- Edits made inside the generated files: pill `button` radius and 44px sizes;
  44px `input`, `native-select` and `toggle`; a `swatch` toggle variant and size;
  outline toggles that mark `data-state=on` and `aria-current` with a foreground
  border and strike through when disabled; `button-group`'s last child rounded to
  match pills; `input-group` at 40px and pill-shaped; `card` titles at `text-xl`;
  `pagination` links as `next/link`; accordion content no longer underlines links;
  `carousel` reads Embla's scroll state with `useSyncExternalStore` (the generated
  effect set state synchronously and failed `react-hooks/set-state-in-effect`);
  `toggle.tsx` without `"use client"` so Server Components can call
  `toggleVariants`.
- Removed dependencies: `@radix-ui/react-dialog` (now `radix-ui`), `clsx` (now `cn`),
  `motion` (the header slide is a CSS transform; the gallery is Embla).
- `package.json`: `typecheck` runs `next typegen` before `tsc`, so `PageProps` and
  `LayoutProps` exist without a prior build.

## Decisions

### Decision: `cn` from the `cn` package, with no `lib/utils.ts`

**Decision**

`components.json` points the `utils` alias at the `cn` package that `shadcn init`
installed, instead of a re-exporting `lib/utils.ts`.

**Reason**

`convention.md` forbids a `utils.ts`, and a file that only re-exports a package is
an indirection with no owner.

**Consequence**

`convention.md` no longer says there is no tailwind-merge: `cn` merges classes, which
is what shadcn's variant overrides rely on.

### Decision: no shadcn `form`

**Decision**

Forms compose `Field` and friends directly. The `form` component is not installed.

**Reason**

It is built on react-hook-form, and the repository has no form library by
decision.

**Consequence**

Server errors are mapped onto fields by name, as before.

### Decision: filters stay links, styled with component variants

**Decision**

Brand, size and shade filters are `next/link`s styled with `toggleVariants`; the
category, price and availability filters are text links. The groups sit in an
`Accordion` that starts fully open.

**Reason**

ADR 0004 and the no-JavaScript rule: a `Checkbox` or `ToggleGroupItem` is a button,
cannot be nested in a link, and does nothing before hydration.

**Consequence**

A filter looks like a toggle and behaves like navigation. On a phone the open rail
sits above the grid.

## Gotchas

- macOS's filesystem is case-insensitive: `Button.tsx` and `button.tsx` collide. The
  old primitives had to be removed before `shadcn add`.
- Radix `ToggleGroup type="single"` sends `""` when the chosen item is pressed
  again. `VariantPicker` turns that into "nothing chosen".
- jsdom lacks `ResizeObserver`, `IntersectionObserver` and `matchMedia`; cmdk,
  Radix and Embla need them. `tests/setup.ts` stubs them.
- Embla never settles on a slide in jsdom. `Gallery.test.tsx` mocks
  `embla-carousel-react` with a stand-in API.
